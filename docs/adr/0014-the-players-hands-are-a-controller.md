# The Player's hands are a Controller, and the selection is not state

The human is the fourth implementation of the one seam (ADR-0003), not a privileged path into the rules. A click, a drag, a key and a control group end at `input/human.ts`, which queues an order and emits it on the next tick the Match decides as a `move`, `attackMove`, `hold`, `withdraw`, `formation` or `group` Command — the same Commands the built-in AI will emit (D3) and an external agent will write on a line (E1). Nothing in the interface moves a Squad; it asks. Swapping the human's Controller for a machine's is a change of one object, which is what makes a recorded human Match replayable and an AI-versus-AI Match a test.

What the Player *owns* rather than commands is memory: the **selection** (the Squads an order goes to, and the settlement whose panel is open) and the **control groups**. Both live in `input/`, are hashed by nothing, are seen by nobody else, and can be discarded without changing the Match. The vocabulary has a `group` Command and it is deliberately a Command that commands nobody: it exists so that a log can re-enact the *selection* as well as the orders (E2), not because the rules care who is in group 2.

Picking is by *drawn rectangle* rather than by tile. A Squad stands on one tile (ADR-0004) but is drawn as a block of a hundred and twenty men standing three tiles up out of it, so a click on a soldier's chest has to select him; the rectangle the renderer composes and the rectangle the pick tests against are the same one, produced by the same module. A box picks every block it touches, and overlapping blocks are resolved the way they are drawn: the one furthest down the screen is the one on top and the one a Player meant.

**Considered Options**: the interface calling rules functions directly — rejected because it would be a second control surface, one that an AI could not use and a replay could not record, and because the plan's whole testability argument rests on there being exactly one. Selection kept as authoritative state so that a replay restores it — rejected because it decides nothing: two Matches differing only in what a Player had clicked are the same Match, and putting it in the hash would make every click a divergence. Picking by the Squad's tile — rejected because it makes a block of men un-clickable everywhere except the patch of ground their front rank stands on. Picking by the block's *centre* only — rejected because a Player aims at what they can see, which is the whole block.

**Consequences**: every gesture needs a hook — the page's `selectAt`, `selectIn`, `orderAt`, `orderNow`, `setFormation`, `bindGroup`, `recallGroup` — and the pointer and keyboard are bound to those hooks rather than to the game, so a browser test drives the same path a Player does. A Command whose effect belongs to a later ticket (a `withdraw` is obeyed by combat and morale, C3) is still a real Command today: the seam is what this ticket proves, and the interface shows that it was issued. The selection is pruned against the Observation on every tick, because it is the Player's memory and the world is the thing that can invalidate it. Control groups are pruned the same way, and a group nobody has left is forgotten.
