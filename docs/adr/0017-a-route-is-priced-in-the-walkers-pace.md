# A route is priced in the walker's own pace

C4 gives every Squad type a `pace`: a whole number of tiles' worth of ground it covers for the cost of one, `1` for a man on foot and `2` for a horse. The cost of entering a tile is `route.ts`'s terrain table divided by that pace and rounded up, so the ground is still the ground: a road costs a horse one tick, plain ground two, a ford five.

The decision is that the **search** uses the same arithmetic. A horse does not walk a footsoldier's route faster; `findRoute` weighs every edge with `paceCost(terrain, pace)`, and the heuristic counts in the cheapest tile *at that pace*, so the route a horse is given is the quickest route for a horse. The route cache is keyed by pace as well as by its two ends, because two walkers of the same ground may take different ways and remembering one answer for both would answer the second walker with the first walker's route.

**Considered Options**: price routes on foot always and scale only the ticks a Squad waits — rejected because `ceil` is not additive: the cheapest footsoldier route is not always the cheapest horse route, so a fast Squad could be sent the slow way and the difference would be invisible in every test that only walked plain ground. Give `pace` as a percentage multiplier applied to the whole route — rejected because it moves the cost into a float or a rounding step at the end of a path, where the terrain costs would no longer be the same numbers the search chose by. A second `RouteCache` per pace — rejected because the cache is a memo and one map holds one; a keyed entry is the same thing with one owner.

**Consequences**: `moveCost` stays the terrain's own price and `paceCost` is the walker's, so a reader has both numbers in hand; the search's admissibility argument is unchanged, because the cheapest step at a pace is still a constant. A content `pace` of `1` leaves every existing route, hash and golden byte-identical, which is what makes C4's `march` and `economy` goldens unchanged. `paceOf(squad)` falls back to the footsoldier's pace for a Squad whose type the content table cannot name, so a bad code is slow rather than a division by zero.
